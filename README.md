# AI Travel Concierge

A Streamlit app that turns trip constraints (destination, travelers, duration,
budget, focus, and must-see/must-do requests) into a full day-by-day
itinerary, generated by Gemini (with a Groq/Llama fallback if Gemini is
unavailable).

## How it works

- `app.py` -- Streamlit front-end. Collects trip details in a sidebar form.
- `generate.py` -- builds a "planning package" (agent instructions + the
  user's requirements) and sends it to Gemini to produce the itinerary.
- `destinations/{city}/highlights.txt` -- curated local knowledge (food,
  sights, neighborhoods, practical tips) for a handful of cities. When the
  destination typed in the app matches one of these folders (exact, alias, or
  fuzzy match), its highlights are automatically injected into the prompt as
  reference material -- a lightweight RAG step so the model grounds the plan
  in real local knowledge instead of guessing. Add a new folder with its own
  `highlights.txt` to extend coverage to more cities.
- `destinations/{city}/must_haves.txt` -- used only by the CLI path
  (`python3 generate.py <city>`), which replays a specific saved request for
  that city. Unrelated to the Streamlit app's own "Must-See / Must-Do" field.

## Local development

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # fill in GEMINI_API_KEY (and optionally GROQ_API_KEY)
streamlit run app.py
```

## Running with Docker

```bash
docker build -t travel-concierge .
docker run --rm -p 8501:8501 --env-file .env -v "$(pwd)/output":/app/output travel-concierge
```

Then open http://localhost:8501. Generated itineraries are also saved under
`output/`.

## Environment variables

| Variable         | Required | Purpose                                   |
|------------------|----------|--------------------------------------------|
| `GEMINI_API_KEY` | Yes      | Primary generation engine (Gemini).        |
| `GROQ_API_KEY`   | No       | Fallback engine if Gemini errors out.       |

Never commit `.env` -- it's gitignored. On Streamlit Community Cloud, set
these under your app's **Settings > Secrets** instead (see below); `app.py`
mirrors them into the process environment at startup so `generate.py` picks
them up unchanged.

## Deploying to Streamlit Community Cloud

1. Push this repo to GitHub (already done if you're reading this from the repo).
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click **New app**, pick this repo/branch, and set the main file path to
   `app.py`.
4. Under **Advanced settings > Secrets**, add:
   ```toml
   GEMINI_API_KEY = "your-key-here"
   GROQ_API_KEY = "your-key-here"
   ```
5. Deploy. Streamlit Cloud installs `requirements.txt` automatically. Share
   the resulting `*.streamlit.app` URL with anyone you want to give access to
   the app.

Every push to the connected branch redeploys the app automatically.
